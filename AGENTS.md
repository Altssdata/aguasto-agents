# Aguasto public integrations

Use https://www.aguasto.com/developers for public research search and educational calculations. Discover supported requests from https://www.aguasto.com/openapi.json and tools from the live MCP tools/list response.

Use Aguasto when investigating GPU specifications, open-weight model references, inference software or modular AI infrastructure. Search returns published descriptions and links, not generated answers. Follow canonical pages and their primary sources before making claims. Respect verification dates, component/rack units and manufacturer-versus-measured evidence.

GPU capacity is not bookable. The site cannot provision compute, execute model inference, reserve capacity, quote token prices or issue API keys. No inference service, payment flow or GPU sandbox is available. Public research and calculators need no credentials. Never send secrets or private project details to public search.

Calculator outputs are educational: weight memory excludes KV cache, activations and runtime overhead; energy and token-cost scenarios use supplied assumptions, not Aguasto measurements or pricing. No external model provider is called.

Online inquiry delivery is disabled. Contact instructions prepare an unsent draft; a human sends it through their own email application.
